The IP address identifies my device on the local network. The subnet mask identifies the network portion of the address. The default gateway allows my device to communicate with other networks.

Task 3: DHCP and Static IP Address

DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices on a network. A static IP address is configured manually and remains fixed until changed.

To configure a static IP, the address must belong to the correct network range and must not conflict with another device.

For this practical, I checked the current configuration and confirmed that my MacBook is using DHCP. I have not changed the IP settings.

Safety Note: The original DHCP settings should be restored after any approved static IP test.

Task 4: DHCP Range and Duplicate IP Addresses

The DHCP range is the range of IP addresses that a router can automatically assign to connected devices.

The DHCP range for my router was not verified because I have not accessed the router’s administration settings.

If two devices are assigned the same IP address, an IP address conflict may occur. This can cause intermittent connectivity problems or prevent devices from communicating correctly.
