Task 3: Steps to Attach an RJ45 Connector

1. Strip the outer cable jacket using a cable stripper.
2. Untwist and straighten all eight wires.
3. Arrange the wires in T568B colour order.
4. Trim the wires evenly.
5. Insert all wires into the RJ45 connector.
6. Use an RJ45 crimping tool to crimp the connector.
7. Test the cable using a network cable tester.
